# CreatorOS roadmap

## Phase 1 — preserve and standardize (current)

- Create the hybrid repository family.
- Separate system code from private content.
- Preserve existing research in the correct systems.
- Define initial contracts and repository boundaries.
- Add minimal working selection and workspace-generation prototypes.
- Initialize local Git repositories and verify that content is excluded.

## Phase 2 — reusable production modules

- Extract reusable Remotion scenes and caption components.
- Add narration cleanup and music-mix presets.
- Add license capture and QC scripts.
- Generate new episode workspaces from a validated manifest.

## Phase 3 — live Tool Arsenal

- Expand structured catalog records.
- Add source freshness checks.
- Run scheduled research that proposes pull requests.
- Add reproducible tool benchmarks.

## Phase 4 — Creator Brain

- Add weighted tool selection and fallback plans.
- Validate all inputs and outputs against versioned schemas.
- Add budget, licensing, hardware, and platform-policy constraints.

## Phase 5 — Growth Intelligence

Start only after enough published episodes exist to establish useful baselines.
