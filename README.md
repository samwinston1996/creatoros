# CreatorOS

CreatorOS is a modular, AI-assisted operating system for producing accurate, original, rights-safe educational content. It separates tool intelligence, planning, execution, governance, and private content so each can improve independently.

## Phase 1 repositories

| Repository | Purpose | May contain real episode content? |
|---|---|---|
| `creator-tool-arsenal` | Evidence-backed catalog of available tools | No |
| `creator-brain` | Requirement-driven tool and workflow selection | No |
| `creator-production-platform` | Reusable production engines, templates, and QC | No |
| `creator-governance` | Claims, rights, policy, and approval contracts | No |
| `creator-content-workspace` | System for creating local/private content workspaces | No |

Real episodes live under `workspaces/content/`, outside all five repositories.

## Non-negotiable boundaries

1. GitHub repositories contain systems, schemas, tests, templates, and sanitized examples only.
2. Narration, raw footage, licensed media, credentials, analytics exports, and real episode folders remain local or in separately approved private storage.
3. Tool and policy facts require source URLs and review dates.
4. The Brain creates transparent plans; it does not silently choose tools.
5. Human approval is required for claims/script, final quality, and public posting.

See `ARCHITECTURE.md`, `ROADMAP.md`, `PROJECT_STATUS.md`, and `MIGRATION.md`.
